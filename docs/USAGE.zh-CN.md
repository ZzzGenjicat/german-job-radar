# 使用说明

无需安装 Python。下载 [Windows ZIP](https://github.com/ZzzGenjicat/german-job-radar/releases/latest/download/GermanJobRadar-Windows-x64.zip)，解压后双击 **GermanJobRadar-Windows-x64.exe**。首次启动不会搜索；支持 Windows 10/11 x64。

## 设置并搜索

1. 打开“搜索设置”，填写职业、技能或业务方向，每行一个，也可用逗号分隔。可直接编辑或删除；旧版停用词可展开恢复。
2. 选择正式岗位、实习或学生兼职，以及是否只接受全职。只填 HR、CRM 等主题词即可；程序按岗位类型生成实际查询词。选择正式岗后，旧 Praktikum / Intern 前缀会去掉，再按所选类型筛选结果。
3. 选择招聘来源、填写排除词（例如 Junior），一起点击“保存设置”或“保存并搜索”。未保存编辑不会被后台刷新覆盖；退出编辑前会提示。
4. 右侧“下次搜索条件”只展示已保存的实际查询词。下方岗位仍属于原批次，重新搜索后才更新；本轮究竟查了什么可在“检索记录”核对。

首轮关键词扩展可关闭：本机词库中的相关词需在至少两份不同候选 JD 中出现，最多增加10个，下次搜索使用。词库覆盖有限；候选足够后只执行一次，删除或改名的词不自动恢复。设置里可查看依据。

## 查看和导出

“待人工筛查”保留所有候选，“已排除”显示排除原因。查看卡片依据和读取到的正文，再打开来源或申请链接核对；链接使用系统默认浏览器。

默认只看本机历史中没出现过的岗位；取消勾选可看本轮全部。“保存默认显示”用于确认下次的默认规则。岗位序号在本批次内固定。

CSV 始终导出本轮两个列表全部岗位，包含页面隐藏的已出现岗位。首行是“德国岗位雷达（只作为建议）”，下一行是列名；序号和页面一致。

## 来源与自动搜索

预置 Arbeitsagentur 和部分地区招聘网站。新增只填名称和 HTTPS URL，网址会规范化为网站根地址；测试搜索页和一个详情可读才添加。任意网址不保证适配。每词最多读取两页、每来源最多35个近期候选；下方“检索记录”显示实际词、查询链接及读取结果，不代表穷尽全网。

在“自动搜索”启用、选择时间并保存，默认周一至周五德国时间18:00，自动适应夏令时。定时在本机执行；电脑需开机、联网并保持 Windows 登录，关闭窗口仍可运行。错过时间会补抓当天未完成批次；当天已完成则不重复。白天手动扫描不取消当天自动搜索。

## 可选的 CV 与 AI

展开“CV 与 AI 分析”可保存自己的 OpenAI API Key、上传 PDF/DOCX，并生成关键词草稿。AI 可能收费；ChatGPT 订阅不包含 API Key。普通搜索、本机扩词和导出都不需要它。

上传仅在本机提取文字。点击 AI 分析才发送简历文字（最多30,000字符）和求职目标；不发送原文件。岗位“不适合我”分析发送岗位内容、反馈、目标和现有规则，不发送简历。确认草稿后才影响类似岗位；已确认规则可停用或删除。

密钥保存在 Windows 凭据管理器。AI 请求不保存响应，服务商仍可能按其政策保留监控记录。删除本机简历无法撤回已发送文字。请勿公开本机数据、简历、日志或个人 CSV。

更新、退出和启动排错见 [Windows 下载版说明](WINDOWS.md)。
